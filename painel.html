WhatsApp dos responsáveis

Cadastre até três números. As mensagens são abertas no WhatsApp com texto preenchido; o envio é manual e não há API de mensagens configurada.

Como enviar avisos

Na aba Solicitações, use “Avisar responsáveis” para preparar a mensagem. Para o solicitante, use “WhatsApp do solicitante” após decidir. Sempre confirme o envio no aplicativo.

✦ AVA — assistência inteligente

A AVA gera análise dos pedidos recebidos quando a API OpenAI está disponível. Os dados e status vêm do Supabase; a IA não aprova reservas.
